# Power BI Dashboard — SAC

> **Projeto de treino e portfólio em Power BI**

## 📊 Sobre o projeto

Este projeto foi desenvolvido como parte do meu treinamento prático em **Power BI**, com o objetivo de aplicar conceitos de análise de dados, criação de indicadores e desenvolvimento de dashboards.

O dashboard apresenta uma análise do setor de **Serviço de Atendimento ao Cliente (SAC)**, transformando dados de atendimento em informações visuais para facilitar a interpretação dos principais indicadores.

## 🎯 Objetivo

Praticar a construção de um dashboard no Power BI, trabalhando conceitos como:

* Tratamento e organização dos dados
* Criação de indicadores (KPIs)
* Visualização de dados
* Análise de informações de atendimento
* Construção de um dashboard orientado a indicadores

## 📌 Indicadores

O dashboard apresenta indicadores relacionados ao atendimento, incluindo:

* Total de chamadas
* Chamadas atendidas
* Chamadas não atendidas
* Chamadas transferidas
* Outros indicadores de atendimento

## 🗂️ Fonte dos dados

Os dados utilizados neste projeto são provenientes da **Base SAC disponibilizada pela Hashtag Treinamentos**.

O dataset original **não é redistribuído neste repositório**. O objetivo deste repositório é apresentar o desenvolvimento e o resultado do projeto de análise e visualização dos dados.
